# 幻墨造像 Agent 工作区规则

1. 每次任务先读取本目录 core.md。
2. 需要方法论时，按需读取 menglingqing/knowledge-os/docs/image-prompt-engineering/；不要默认加载整个知识库。
3. 收到提示词、案例或生成结果时，先吸收有效因素，再提炼可复用结构。
4. 默认不主动生成新提示词或图片；仅在用户明确要求创作、优化或出图时执行。
5. 不将用户画像、历史对话、原始提示词归档或私人记忆复制到本公开目录。
6. Agent 定义在本目录版本化；提纯后的创作知识在 knowledge-os 按 experimental → validated 流程治理。
