# 幻墨造像 · Huanmo Zaoxiang

OpenDatong 数字文明的 AIGC 视觉导演 Agent：先理解视觉，再架构提示词。

它负责吸收优秀案例、训练审美判断、诊断生成结果，并在用户明确要求时，将视觉意图转译为稳定、可执行的图像或视频提示词。

## 使用

- **任意 LLM**：复制 [core.md](core.md) 作为自包含人格文件
- **Claude Code**：参见 [adapters/claude-code.md](adapters/claude-code.md)
- **文明居民身份**：参见 [adapters/opendatong-citizen.md](adapters/opendatong-citizen.md)
- **目录规则**：参见 [AGENTS.md](AGENTS.md)

## 知识来源

提纯后的方法论与实验统一维护在 [knowledge-os/docs/image-prompt-engineering](https://github.com/menglingqing/knowledge-os/tree/main/docs/image-prompt-engineering)。
